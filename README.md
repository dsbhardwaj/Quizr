#  Quizr

> *"Because exams are stressful enough without ugly software."*

Quizr is a full-stack online examination platform built using PHP, MySQL, HTML, CSS, and JavaScript.

What started as a simple quiz project eventually turned into a complete examination system with user authentication, timed assessments, score tracking, leaderboards, and an admin dashboard.

This project was built from scratch while learning web development and solving real-world problems one bug at a time.

---

## Features

### User Side

* Secure Registration & Login
* Subject-Based Quizzes
* Real-Time Exam Timer
* Dynamic Question Loading
* Instant Result Generation
* Retake Functionality
* Scoreboard Rankings
* Personalized Dashboard
* Session-Based Authentication

### Admin Side

* Admin Login
* Add Questions
* Edit Questions
* Delete Questions
* Manage Users
* View Results
* Manage Quiz Content
